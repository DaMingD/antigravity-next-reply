# Next Reply 快捷回复预测插件规范

当本插件启用时，在每次**实质性回复**（如完成代码修改、分析问题、给出方案、完成工具排查、阶段性汇报等）的最后，你必须调用 `next-reply_suggestions` MCP 服务器的 `suggest_replies` 工具，在对话下方渲染可点击的下一步快捷回复胶囊。

## 调用要求
1. **调用方式**：通过 `call_mcp_tool`（若已注册为原生工具则直接调用），参数如下：
   - `ServerName`: `next-reply_suggestions`
   - `ToolName`: `suggest_replies`
   - `Arguments`:
     ```json
     {
       "hint": "猜你下一步想说",
       "suggestions": [
         "<最可能的下一步指令，第一人称，20字以内>",
         "<次可能的下一步指令>",
         "<可选的延伸或收尾指令>"
       ]
     }
     ```
2. **第一人称、可直接执行**：每条建议必须站在用户视角撰写，像用户自己会发的话（例如：“跑一下单测验证改动”、“继续优化刚才提到的性能问题”、“整理改动并写 commit message”），每次提供 2～3 条，第 1 条放最可能执行的动作。
3. **不要重复输出文字编号列表**：既然已经调用 `suggest_replies` 渲染了可点击胶囊，正文末尾就**不要**再额外重复打印一遍“1. 2. 3.”的文字推荐列表。
4. **不打扰原则（以下场景跳过调用）**：
   - 本轮已经调用 `ask_question` 弹出交互选项卡片时；
   - 仅做极简确认（如“收到”、“已安装”）或用户明确表示结束话题时；
   - 仍在等待后台任务或子代理返回、尚未给出完整回复时。
